# Документы Z-TraderBot

Обновлено: 2026-10-14.

Проект исследует, способен ли ИИ самостоятельно улучшать методы анализа рынка.
Сейчас уточняется отдельная задача определения диапазонов; эксперимент и реализация ещё не начаты.
Этот файл — навигация для человека и справка об организации документов; для начала исследования читать его необязательно.

## Вход в новый чат

Открой чат в корне проекта и передай один из запросов:

- Большая задача: «Прочитай .agents/plans/global.md и продолжи по его текущему шагу».
- Диапазоны и каналы: «Прочитай .agents/plans/range-detection.md и продолжи по его текущему шагу».

Каждый план содержит достаточный контекст для начала своей задачи и условия чтения дополнительных материалов.
Если чат не имеет доступа к папке, передай выбранный план и роль, затем только нужные по задаче материалы; путь к файлу не передаёт его содержимое.

## Как подключается контекст

Codex обнаруживает AGENTS.md по расположению проекта и рабочей папке; обычная Markdown-ссылка сама по себе не включает другой файл в системный промпт.
Здесь AGENTS.md задаёт условия, при которых агент явно читает дополнительные документы.
Стартуй из корня: сейчас проект без Git, поэтому запуск из вложенной папки может не обнаружить корневой AGENTS.md.
Это соответствует [официальным правилам обнаружения инструкций](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

Рабочие маршруты: глобальная задача → роль и глобальный план; диапазоны → роль и план диапазонов; локальная правка → затронутый файл.
Второй план, история, исходный документ, отчёт и архив не требуются автоматически.
Это правила поведения агента, а не техническая блокировка чтения файлов; они не удаляют уже прочитанное из текущего чата.
Для чистого контекста начинай новый чат с одним из запросов выше.
