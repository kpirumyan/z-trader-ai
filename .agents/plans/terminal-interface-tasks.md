# Задачи по архитектуре интерфейса терминала

Источник требований: [архитектура интерфейса](../../design/terminal-interface-architecture.md). Общий [реестр задач](tasks.md) хранит коды и статусы; этот файл раскрывает состав работ по интерфейсу. При изменении задачи или её статуса обновлять оба списка и [глобальный план](global.md) вместе. Согласованные критерии находятся в архитектуре, а не заменяются этим чеклистом.

Текущий шаг: **T1.5** — реализовать утверждённый план проектирования кода через TDD и проверить первый вход, обновление, восстановление, обе темы и отсутствие сдвигов. Сценарии создания окон относятся к следующим этапам.

## T0. Принятые основы

- [x] **T0.1** Перенести прежние экраны Stitch в демонстрационную оболочку (исторический результат; оболочка позднее удалена).
- [x] **T0.2** Согласовать свободные перекрывающиеся окна, плитку и каскад только по команде, модель одного рабочего места с возможностью расширения.
- [x] **T0.3** Согласовать пустой первый вход и будущий путь `New` → вид окна → поиск инструмента → новое окно.

## T1. Первый вход и визуальный контракт

- [x] **T1.1** Утвердить состав пустого экрана: верхнюю панель, постоянный фоновый логотип, инструкцию и переключатель темы. В интерфейсе использовать английский язык.
- [x] **T1.2** Согласовать состояния поиска инструмента, восстановления хранилища, фокус и доступность диалога.
- [x] **T1.3** Подготовить и показать первый экран в светлой и тёмной темах с точными брендовыми изображениями.
- [x] **T1.4** Зафиксировать правки и согласовать визуальный ориентир.
- [ ] **T1.5** Реализовать пустое рабочее место по утверждённому плану структуры `app/`:
  - [ ] Верхняя панель и фоновый логотип находятся в исходном HTML; тема и нужные изображения видны до гидратации.
  - [ ] Клиентский слой рабочего места читает версионированное состояние через `use(browser())` внутри `Suspense` с пустым fallback; новый пользователь получает пустое рабочее место без окон.
  - [ ] Инструкция показана только для пустого рабочего места, под логотипом с зазором; `New` открывает доступное пояснение о следующем этапе и пока не создаёт окно.
  - [ ] Ошибки повреждённого и недоступного хранилища показывают согласованные действия; повреждённая запись автоматически не перезаписывается.
  - [ ] Проверить первый вход и обновление, светлую и тёмную темы, узкий экран, загрузку изображений и шрифта: видимой строки ожидания и сдвига панели, логотипа или инструкции нет.

## T2. Создание и управление окнами

- [ ] **T2.1** Уточнить вид `New`, изменение инструмента внутри окна и правила фокуса. Сохранить единственный путь создания окна через выбор `Chart`, `Level II` или `T & S` и диалог поиска.
- [ ] **T2.2** Спроектировать и реализовать график, аналитический стакан и ленту как отдельные окна, доступные одновременно. Содержимое стакана и ленты сначала может быть демонстрационным.
- [ ] **T2.3** Завершить общую рамку: перемещение, размер, порядок наложения, сворачивание, разворачивание, закрытие, плитку и каскад. Уточнить способ перетаскивания с клавиатуры.
- [ ] **T2.4** Добавить явные цветовые группы связи инструмента и независимые окна вне групп.
- [x] **T2.5** Убрать создание графика через боковой список; дополнительные быстрые пути не вводить.

## T3. Содержимое и сохранение рабочего места

- [ ] **T3.1** Уточнить и реализовать настройки графика: инструмент, таймфрейм, масштаб, объём, SMA/EMA/RSI с параметрами и разметку.
- [ ] **T3.2** Разделить модель окон, рамку, содержимое и хранение по ответственности; сохранить корректные серверную и клиентскую границы.
- [ ] **T3.3** Расширить версионированное сохранение для окон, геометрии, порядка, инструментов, настроек содержимого и цветовых групп.
- [ ] **T3.4** Проверить восстановление после обновления, сбой хранилища, тему, взаимодействия и доступность.
- [ ] **T3.5** Сверить интерфейс в обеих темах с утверждённым визуальным ориентиром.

## T4. Будущие рабочие места

- [ ] **T4** По отдельному запросу спроектировать создание, переключение и сохранение нескольких рабочих мест в пределах принятой модели.

Пульт воспроизведения и рыночные данные относятся к [отложенному плану](terminal-data-replay.md); их реализация не входит в эти задачи.
