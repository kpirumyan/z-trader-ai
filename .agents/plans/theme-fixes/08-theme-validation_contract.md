# Контракт 08: Централизованная валидация темы (Theme Validation)

- **Идентификатор контракта:** `08-theme-validation_contract.md`
- **Связанный пункт аудита:** Пункт 8 (`theme-system_review.md`)

## 1. Архитектура и инварианты (System Architecture & Invariants)

1. **Исключение хардкода литералов:**
   Запрещены ручные проверки вида `saved === 'light' || saved === 'dark'` в коде приложения ([`app/layout.tsx`](file:///c:/DATA/Development/js/z-trader-ai/app/layout.tsx), хуках или сервисах).
2. **Централизация валидации:**
   Проверка валидности темы должна опираться на неизменяемый список `THEMES` из `app/constants/theme.ts`.
3. **Безопасность типов (Type narrowing):**
   Валидатор должен представлять собой TypeScript Type Guard (`isTheme(value: unknown): value is Theme`), сужающий произвольный тип входного значения до доменного типа `Theme`.
4. **Устойчивость к сбоям:**
   Любое невалидное, пустое, поврежденное или нетипизированное значение из хранилища (`localStorage`) должно отклоняться валидатором с безопасным откатом к `DEFAULT_THEME`.

## 3. Критерии приемки (Given / When / Then)

### Сценарий 3.1: Валидация корректных значений темы
- **Given** входное значение `"dark"` или `"light"`
- **When** вызывается `isTheme(value)`
- **Then** функция возвращает `true`, тип значения сужается до `Theme`

### Сценарий 3.2: Отклонение некорректных строк
- **Given** произвольная строка, не входящая в `THEMES` (например, `"system"`, `"blue"`, `""`, `"DARK"`)
- **When** вызывается `isTheme(value)`
- **Then** функция возвращает `false`

### Сценарий 3.3: Отклонение нестроковых и пустых значений
- **Given** значение `null`, `undefined`, число `123`, объект `{}` или массив `[]`
- **When** вызывается `isTheme(value)`
- **Then** функция возвращает `false` без выброса исключений

### Сценарий 3.4: Применение в слое инициализации
- **Given** сохраненное значение в `localStorage` при загрузке страницы
- **When** выполняется инициализирующий скрипт в `RootLayout`
- **Then** парсинг сохраненного значения выполняется с проверкой принадлежности к допустимым темам без дублирования строковых литералов

## 4. Компромиссы и обоснование (Trade-offs & Rationale)

- **Размещение в `app/constants/theme.ts`:**
  В соответствии с правилом `codebase-layout.md`, каталог `app/types/` не может содержать исполняемый рантайм-код или функции. Размещение функции-тайпгарда `isTheme` рядом с объявлением массива `THEMES` обеспечивает максимальную связность (cohesion) без циклических зависимостей.
