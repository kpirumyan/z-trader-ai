## 1. Архитектура и инварианты (System Architecture & Invariants)

1. **Единственное доступное имя (Accessible Name):**
   Кнопка переключения темы должна иметь ровно одну осмысленную текстовую метку для скринридеров в любой момент времени. Запрещено монтировать два одновременных тега `.sr-only` с расчетом на сокрытие через CSS `display: none`.
2. **Семантическое состояние переключателя:**
   Кнопка является переключателем состояния (toggle button) и обязана сообщать о своем текущем состоянии с помощью атрибута `aria-pressed={isDark}`.
3. **Соответствие `DESIGN.md`:**
   - Фокусные стили: контур 2px золотого токена `var(--brand-gold)` с отступом `outline-offset: 1px`.
   - Иконки: SVG сохраняют `aria-hidden="true"`, правильные пропорции 18×18 px и классы темы.
4. **Текстовые метки:**
   - Когда активна тёмная тема (`isDark: true`): действие кнопки — переключиться на светлую тему. Текст: `"Switch to light theme"`.
   - Когда активна светлая тема (`isDark: false`): действие кнопки — переключиться на тёмную тему. Текст: `"Switch to dark theme"`.

## 3. Критерии приемки (Given / When / Then)

### Сценарий 3.1: Доступное имя и состояние в тёмной теме
- **Given** активна тёмная тема (`isDark === true`)
- **When** рендерится компонент `ThemeToggle`
- **Then**:
  1. Вычисленное доступное имя кнопки (accessible name) строго равно `"Switch to light theme"`;
  2. Атрибут `aria-pressed` равен `"true"`;
  3. В DOM присутствует ровно один элемент `.sr-only`.

### Сценарий 3.2: Доступное имя и состояние в светлой теме
- **Given** активна светлая тема (`isDark === false`)
- **When** рендерится компонент `ThemeToggle`
- **Then**:
  1. Вычисленное доступное имя кнопки строго равно `"Switch to dark theme"`;
  2. Атрибут `aria-pressed` равен `"false"`;
  3. В DOM присутствует ровно один элемент `.sr-only`.

### Сценарий 3.3: Управление с клавиатуры
- **Given** фокус установлен на кнопку `ThemeToggle`
- **When** пользователь нажимает клавишу `Space` или `Enter`
- **Then** вызывается функция `toggleTheme()`, состояние переключается, и доступное имя обновляется на противоположное без потери фокуса

## 4. Компромиссы и обоснование (Trade-offs & Rationale)

- **Почему `aria-pressed`, а не `role="switch"`:**
  Нативный элемент `<button>` с атрибутом `aria-pressed` является стандартным шаблоном WAI-ARIA "Toggle Button", поддерживается 100% скринридеров (NVDA, JAWS, VoiceOver) и не требует дополнительных обработчиков `keydown` для эмуляции поведения свитча.
