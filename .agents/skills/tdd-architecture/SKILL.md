# TDD с архитектором

Оставайся [оркестратором](../../roles/orchestrator.md). Установи `architecture=required` и выполни [общую основу TDD](../../workflows/tdd-base.md), включая архитектурный этап до тестов.

Архитектор — отдельный сабагент по [назначенной роли](../../roles/architect.md). Его решение передаётся остальным исполнителям и проверяется независимым ревьюером. Это вход для реализации; скилл `$architect` остаётся отдельным режимом обсуждения без автоматического запуска TDD.
