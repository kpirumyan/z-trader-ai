# TDD без архитектора

Оставайся [оркестратором](../../roles/orchestrator.md). Установи `architecture=none` и выполни [общую основу TDD](../../workflows/tdd-base.md).

Этот вход не снижает требования к документации, качеству архитектуры и UX. Если обнаружен нерешённый архитектурный выбор, используй правило смены маршрута из общей основы. Для работы с отдельным архитектором предназначен `$tdd-architecture`.
