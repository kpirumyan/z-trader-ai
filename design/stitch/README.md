## Реализация

`app/terminal.tsx` — общий интерфейс обеих тем; `app/globals.css` — оформление; `app/chart-artwork.ts` — статические SVG, извлечённые из экспорта и адаптированные к CSS-палитрам. Шрифты Geist и JetBrains Mono поставляются локально через @fontsource.

Работают поиск, открытие демонстрационных ES/NQ, перемещение и изменение размеров окон, сворачивание, разворачивание, закрытие с отменой, раскладка, темы и локальное сохранение. Показаны три исходных графика. Отсутствующие интервалы и рисование отключены с пояснением.

Графики, RSI, объём, SMA/EMA и разметка — иллюстрации. Нет расчётов, масштабирования истории, редактора индикаторов и подключения к рынку. Эти функции требуют следующего этапа по DESIGN.md.

## Запуск и проверка

В Git Bash: `pnpm install`, затем `pnpm dev`. Открыть http://localhost:3000 в окне не меньше 1024 × 720. Проверки: `pnpm typecheck`, `pnpm build`. Обе прошли; темы визуально проверены при 1440 × 900.
