# Отложенные сценарии рабочего места

`terminal-workspace.spec.ts` сохраняет будущие сценарии из прежнего `tests/e2e/home.spec.ts`. Пользователь разрешил вывести их из текущего запуска, сохранив покрытие и устранив дубликаты. Playwright выбирает `tests/e2e`; эта папка в активный набор не входит. `skip`, `todo`, исключения в конфиге и отдельные команды не используются.

Первая строка T1.5 (исходный HTML оболочки, тема, изображения и стабильная геометрия) проверяется `tests/e2e/terminal-shell.spec.ts`. Для второй строки активен `tests/e2e/terminal-workspace.spec.ts`: создание одного пустого рабочего места, устойчивый id после reload, чтение сохранённой записи, отсутствие чтения workspace до клиентского JS и сохранение оболочки при чтении и отказах хранилища. Повреждённая запись сохраняется без автоматической перезаписи. RED → GREEN, независимое ревью и финальный `pnpm check` подтверждены 2026-10-20.

## Когда возвращать сценарии

Оркестратор переносит согласованную группу в активный набор через TDD перед реализацией соответствующей следующей строки T1.5. Перед переносом нужно сверить публичный контракт; будущее поведение пока не подтверждено запуском.

| Группа | Условие активации |
| --- | --- |
| Создание и сохранение одного пустого рабочего места; reload | Активировано во втором пункте в `tests/e2e/terminal-workspace.spec.ts`; прежний отложенный сценарий теперь проверяет только будущую инструкцию на первом входе и reload |
| Инструкция появляется после клиентского чтения без строки ожидания | Реализуется инструкция пустого рабочего места |
| Инструкция до загрузки PNG и шрифтов; зазор под рисунком, перенос при 320px, отсутствие сдвига | Реализуется инструкция и её финальная геометрия в обеих темах; измерение шрифта начинается до `document.fonts.ready` |
| Недоступные PNG не блокируют инструкцию и объяснение `New` | Реализуется инструкция и поясняющий диалог `New` |
| Повреждённая запись, сохранность до `Start empty`, повторное чтение `Retry` | Отсутствие аварии и автоматической перезаписи уже покрыты активным набором; действия восстановления активировать при реализации соответствующего пункта |
| Недоступное хранилище оставляет инструкцию и предупреждает о несохранении | Отсутствие аварии при getter/getItem/setItem уже покрыто активным набором; инструкцию и предупреждение активировать при реализации соответствующего пункта |
| Пояснение `New`, клавиатурное открытие и возврат фокуса | Реализуется доступный поясняющий диалог; это не контракт открытия окон |

## Дедупликация

Самостоятельный старый тест темы заменён активными сценариями системной темы, сохранённого выбора, исходного кадра, reload и отказов хранилища. Старые самостоятельные проверки оболочки до гидратации и брендовых ресурсов также объединены в активном наборе. В отложенном наборе остались проверки, зависящие от будущей инструкции или workspace state.

Старые две проверки PNG в обеих темах и восемь проверок геометрии объединены в восемь сценариев инструкции: обе темы × 1440/320px × первый вход/reload. Они сохраняют готовность инструкции до PNG, её расположение под рисунком, перенос и стабильность текста при загрузке PNG и шрифтов. Геометрия постоянной панели и брендовых изображений проверяется активным набором, поэтому здесь не повторяется. Прозрачные поля PNG допускается кадрировать: положение текста сравнивается с видимым низом рисунка с учётом `object-fit` и overflow предков.

Вызовы переключателя темы в сценариях рабочего места проверяют сохранение инструкции во время действия; самостоятельные утверждения о теме остаются в активном наборе.
